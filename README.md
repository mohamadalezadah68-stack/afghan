# Afghan web apps

A collection of small, browser-based apps.

## World clock

Open [`clock.html`](clock.html) to view live clocks for Kabul, London, New York, and Tokyo. Add or remove time zones; your selection is saved in browser local storage. Time display uses the browser's built-in time-zone database and updates automatically, including daylight saving changes.

## Weather dashboard

Open [`index.html`](index.html) to search for a city or use your location to view current conditions, an hourly forecast, and a five-day forecast. Weather data and geocoding are provided by [Open-Meteo](https://open-meteo.com/).

## Random joke generator

Open [`joke.html`](joke.html) and select **Another joke** to fetch a random joke from [icanhazdadjoke.com](https://icanhazdadjoke.com/). You can also copy the joke to share it. No API key or build step is required.

All apps are responsive and run entirely in the browser. Open the corresponding HTML file to get started.
